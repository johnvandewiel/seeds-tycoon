# Seeds Tycoon

Gamified influencer affiliate dashboard ("Sunny Garden") for amsterdammarijunaseeds.com.

- **Try the prototype:** open `prototype/index.html` in a browser (no build step). Use "Demo: simulate a day of traffic" to see plants grow, quests complete and the level-up.
- **Spec:** `HANDOFF.md` covers game rules, money, attribution, the Medusa v2 data model and build order.
- **Continue on your server:**
  ```bash
  git clone https://github.com/johnvandewiel/seeds-tycoon.git
  cd seeds-tycoon
  claude   # then: "read HANDOFF.md and start with step 1"
  ```
